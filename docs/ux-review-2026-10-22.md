# UX review, 2026-10-22: the work list

This review comes from screenshots of all player and owner pages on desktop (1280px) and phone (390px). **The product owner approved fixing all items below.**

Respect these decisions:
- football only
- 2 fields per place (5×5 and 11×11)
- booking is a request that the field accepts
- login through Telegram
- no player levels
- games are "N vs N" without a field
- dark theme with a lime accent

## Global design system (shared)
- **G1. Color tokens** (`resources/css/bookball.css`). Use them everywhere, never raw colors:
  - `--field-small` (5×5), `--field-big` (11×11)
  - status colors:
    - `--st-pending` (amber) for waiting
    - `--st-confirmed` (green) for accepted
    - `--st-manual` (violet) for owner-made
    - `--st-off` (grey) for cancelled, expired or declined
  - Lime (`--accent`) is reserved for the main action. No off-palette cyan buttons.
- **G2. Disabled buttons:** solid surface color with muted text and no gradient (not a muddy, faded gradient). Always show why a button is disabled, in a helper line right above it.
- **G3. One avatar:** the `components/Avatar.vue` component. Initials on a color derived from the user id, always a circle. Use it everywhere a person is shown.
- **G4. Typography:**
  - The display font is only for the brand, page titles and big numbers.
  - Monospace is only for booking codes and times in pickers.
  - The small labels above titles (`.kicker`) become sentence case, muted, 13px. No spaced-out uppercase.
- **G5. Bottom tab bar (phone):**
  - short labels that fit
  - one name for chats everywhere ("Chats")
  - badges: unread chats, game invites, waiting bookings
- **G6. Header:** no language switch for logged-in users; the language is in Profile. Guests keep it.
- **G7. Footer:** only for guests on public pages. Not under app screens.
- **G8. Date strips:** an edge fade with a scroll hint. "Any day" is a plain outline chip, not a heavy lime block.

## Player: booking
1. **Home:**
   - place cards show up to 4 free-time chips per field, which open the place page with field, date and time preselected
   - when nothing is free today, show "Next free: Thu 19:00" instead of a grey "no time" line
   - on phones the list must start near the top: no big hero search form, one compact filter bar (date strip, All / 5×5 / 11×11, district)
   - hide the "0 free tonight" stat when it is 0
   - the 5×5/11×11 promo cards and "How it works" appear only for guests
   - compact cards: 96px thumbnail, "Indoor"/"Outdoor" text, the price always on its own line, muted text contrast ≥ 4.5:1
2. **Place, time list:**
   - show every start time within opening hours, with taken ones greyed or struck through
   - when the day has nothing free: "Fully booked. Next free: Fri 18:00 →"
3. **Place, phones:**
   - no bottom tab bar on this page
   - the sticky booking bar appears only after a time is picked
   - the summary card has no second "Book" button
4. **Place info:**
   - one compact info list: "Every day 08:00–24:00", prices, the address with "Open in Maps" (lat/lng) and "Call" (venue phone) buttons
   - amenities as plain icon + text, no borders
   - one icon line under the button: "Pay at the field · Free cancellation ≥12 h · Confirmation in Telegram"
5. **My bookings:**
   - no profile block at the top: just the title and tabs. Logout lives only in Profile.
   - group bookings under day headers (Today / Tomorrow / this week / later)
   - compact cards
   - show the countdown only when less than 3h remain, and the free-cancel line only within 24h of its deadline
   - upcoming actions: "Directions" and "Call place", with "Cancel" in a ⋯ menu that asks for confirmation
   - "Book again" only in the Past tab
   - a waiting booking shows one amber badge: "Waiting for the field · usually < 1 h"
   - Telegram: show a thin dismissible banner ("Allow the Bookball bot to send confirmations → Open bot") only when the user has no Telegram chat linked. Never say "not connected" to someone who logged in with Telegram.

## Player: games, chat, friends, profile
6. **Games list:**
   - the card headline is district + preferred day/time, or a "Time TBD" chip
   - the format is a chip, and "4 spots left" is prominent
   - invite cards get a top line "Aram invited you" with Accept/Decline
   - filters: chips All / 3×3–6×6 / 7×7–11×11, plus a "Filters (n)" button that opens a sheet with day, district and time
7. **Create game:**
   - the disabled button follows G2, with "Pick 2 more friends to create" right above it
   - date and time use the app's day chips and time chips ("From"/"To"), not raw native inputs
   - size uses the stepper plus quick chips (5×5, 6×6, 7×7, 8×8, 11×11); no slider
8. **Game page:**
   - one main action (lime) depending on the state ("Open chat" or "Book a field"); the others are outline buttons
   - "Cancel game" is a red text link at the bottom with confirmation
   - remove-player goes in a per-row ⋯ menu, so names aren't cut off
   - one progress bar for the player count
   - free spots collapse into one "+4 free spots · Invite" row
   - "How a game opens" goes behind an (i) toggle
9. **Chat (phones):**
   - full screen (100dvh): no app header, no tab bar, no footer; the composer is pinned with the safe-area inset
   - day separators are rows of their own, not sticky over messages
   - the character counter appears only after 1800 characters
   - consecutive messages from the same sender are grouped
   - a one-line pinned game bar: "Thu 21:00 · Zangak · field not booked → Book"
10. **Chat list:**
    - unread rows in bold with a count dot
    - time as HH:MM today, the weekday this week, then the date
    - a "New message" button that opens a friend picker
    - an empty state with a "Find players" link
11. **Friends:**
    - a segmented Friends | Requests control, plus a "+ Find players" button in the header ("Played with you" goes inside Find players)
    - compact 64px rows: avatar, name, @username, a chat icon button; tap the row for the profile
    - no "You are friends" pill in the Friends tab
    - a search field above the list
    - a 2-column grid on desktop
12. **Profile:**
    - the bio counter counts up (0/300)
    - Save is enabled only when something changed, with "No changes" next to it
    - the phone in the normal font
    - Logout at the bottom

## Owner
13. **Today:**
    - the main block is a two-lane "Today" strip (5×5 | 11×11) with a now-line: the current booking plus the next 3 on each field
    - the 7-day chart moves to the bottom
    - request cards show the phone as a `tel:` link and a "Conflicts with …" chip when it overlaps another request
    - Accept/Decline give a toast with "Undo" (5 s)
    - one "+ New booking" in the header (on phones a floating button above the tab bar), with no duplicate "Open schedule" button
    - KPI labels are sentence case on one line, with one number format ("280 000 ֏" or "280k ֏" everywhere, not both)
    - "Added by you" becomes "Manual"
    - a banner "Connect Telegram to get requests instantly" until the owner connects
14. **Schedule:**
    - unanswered requests whose time has passed show as "Expired" (grey outline)
    - text stays full-contrast; only block backgrounds are dimmed
    - below 768px: a 5×5 | 11×11 segmented toggle with one full-width lane
    - date controls: the day strip plus one calendar button, and a "Now" button that scrolls to the now-line
15. **Settings:**
    - on phones, rule rows stack (label, description, control)
    - one sticky "Save changes" bar that appears when something changed, instead of 4 save buttons
    - the place phone is editable ("+ Add phone")
    - prices are shown with thousand separators and ֏
    - a "Same hours every day" toggle, on by default

## Telegram bot
16. **Language:**
    - a "🌐 Language" button on the bot's login and welcome messages, and a `/language` command
    - it shows 🇦🇲 Հայերեն / 🇷🇺 Русский / 🇬🇧 English
    - the choice changes the user's language for both the bot and the website
